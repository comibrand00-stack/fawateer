# فواتيري — النشر السحابي الدائم (Render + PostgreSQL)

هذا المجلد هو نسخة التطبيق الجاهزة للنشر على **Render** (خدمة مجانية) مع
قاعدة **PostgreSQL** من Render نفسه (بدون أي حساب خارجي آخر).

يخدّم الملفات الثابتة ويكشف API متوافقاً مع التطبيق المحلي:
- `GET  /api/store` → `{ version, data }`
- `POST /api/op`    → `{ ops: [...] }`
- `POST /api/store` → `{ data: {...} }`

---

## خطوات النشر (مرة واحدة، ~10 دقائق)

### 1) إنشاء مستودع على GitHub
1. أنشئ حساباً مجانياً على https://github.com إذا لم يكن لديك.
2. اضغط **New repository**:
   - الاسم: `fawateeri`
   - اجعله **Public**
   - لا تختار أي ملفات تهيئة (empty)
3. **لا تغلق الصفحة** — ستحتاجها لرفع الملفات (الخطوة 3).

### 2) رفع الملفات إلى المستودع (بدون تثبيت git)
1. حمّل ملف `invoice-system/online/` عندك (المجلد بأكمله).
2. في صفحة المستودع: اضغط **Add file → Upload files**.
3. اسحب مجلد `online/` كاملاً (محتواه: `server.js`, `package.json`,
   `render.yaml`, `public/`, файл `.env.example`, `README.md`).
4. اكتب رسالة (مثل "initial") واضغط **Commit changes**.

### 3) ربط قاعدة PostgreSQL في Render
1. ادخل إلى https://render.com وسجّل مجاناً.
2. من لوحة التحكم: **New → PostgreSQL** ⟶ إنشاء قاعدة مجانية (Free).
   - قد يحتاج الشهر الأول مجاني — يكفي للتجربة.
3. انسخ **Internal Database URL** من صفحة القاعدة (واستخدمه إن طُلب).

### 4) نشر الخدمة
من لوحة Render: **New → Web Service** واختر المستودع `fawateeri`.
اطلب واجهة رسومية Enum → ستحدد تلقائياً (Node). أضف في **Environment**:
- `DATABASE_URL` = رابط القاعدة من الخطوة 3 (أو اربط القاعدة من
  صفحة الخدمة → **Linked Resources** → PostgreSQL وستُحقن تلقائياً)

اضغط **Create Web Service** وانتظر (أول نشر 2–5 دقائق). عند اكتماله ستحصل
على رابط دائم ثابت مثل: `https://fawateeri.onrender.com`

### 5) الاستخدام
- افتح الرابط من **أي جهاز وأي شبكة** — نفس البيانات المشتركة.
- يمكن فتح التطبيق من عدة أجهزة في وقت واحد ويتم المزامنة تلقائياً.

## بدون قاعدة بيانات
إن لم تُضِف `DATABASE_URL`، يعمل الخادم بذاكرة مؤقتة (تُمسح عند إعادة
التشغيل) — مناسب للتجربة السريعة فقط.
